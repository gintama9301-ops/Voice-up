IMPORTANT WHEN UPDATING AN EXISTING LOCAL PROJECT
1. Stop the Node.js server before replacing files.
2. Back up and KEEP your current server-data folder. Never replace it with a new empty folder.
3. Copy the updated files into your existing voice-up-complete folder, overwriting files with the same names.
4. Open a terminal in the voice-up-complete folder and run: npm.cmd start
5. Open http://localhost:3000/explore.html, not a local file:/// URL or Live Server.
6. Sign in with two different accounts to test shared supporter counts.
